Updating .agents/AGENTS.md in this repo:

- When updating AGENTS.md, use `$openai-docs` to consult [this guidance](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra.md).
- Write instructions as imperative sentences that state the required action.
- Keep only guidance that changes behavior and is not covered elsewhere.
- Link to authoritative sources and state when to read them; avoid copying.
- Preserve active constraints when shortening; remove obsolete restrictions.
- Merge related guidance and resolve conflicts with existing rules and config.
- Keep policies here; keep versions and execution settings in config files.
